# Fine-Tuning Corpus

The final fine-tuning corpus contains 55,900 instruction-response examples:

- 50,400 general instruction examples sampled from `alpaca_data_zh_51k`
- 5,500 Dou Dizhu decision examples constructed for this study

The `alpaca_data_zh_51k` dataset is released under the Apache License 2.0:
https://huggingface.co/datasets/hfl/alpaca_zh_51k

The mixed corpus used in this study is stored in:

`mixed_train_v11_constraints.json`
